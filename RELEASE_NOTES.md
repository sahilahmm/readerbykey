### What's new in 1.3.5.1

- **Apple support.** Reader now builds for iPhone and iPad too (same look, same offline behaviour). Releases include `Reader-by-Key-unsigned.ipa`; see the README for how to install it and what an App Store release needs. Apple privacy manifest and file types (PDF, Word, text) are included.
- Everything from 1.3.5 (Play and EU readiness) still applies. The Android app is unchanged.
